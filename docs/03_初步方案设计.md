## 1. 系统功能定位

### 1.1 定位描述

本系统定位为**企业数据资产治理平台的可视化展示层**，面向企业管理层、数据安全合规人员和数据资产管理员，以图表化、交互化的方式呈现数据分类分级结果、血缘关系和合规风险态势。

系统核心特点：
- **无后端依赖**：所有数据来自本地 Mock JSON，打包后为纯静态文件，浏览器直接打开运行
- **高保真原型**：界面效果接近真实产品，具备完整的交互能力，可用于汇报演示
- **架构可扩展**：Mock 数据层与组件层解耦，后期可替换为真实 API，平滑升级为生产系统

### 3.2 数据流设计

```
Mock JSON 文件
      │
      │ import (ES Module static import)
      ↓
  Vue 组件 (setup)
      │
      │ ref / reactive
      ↓
  响应式数据
      │
      ├──→ ECharts option (通过 computed 计算)
      │         │
      │         ↓
      │    vue-echarts 组件渲染
      │
      └──→ G6 Graph data
                │
                ↓
           G6 graph.render()
```

**联动设计**：使用 Vue 的 `provide/inject` 或简单的 `eventBus`（mitt 库）实现跨组件数据联动（如点击饼图某类别，自动在血缘图中筛选对应节点）。

## 6. 接口设计（Mock 数据契约）

定义 Mock 数据文件与组件之间的数据契约，为后期接入真实 API 打好基础。

### 6.1 数据模型概览

```
DataTable（数据表）
├── id: string
├── name: string               # 表名
├── domain: string             # 业务域
├── level: 'core'|'sensitive'|'internal'|'public'  # 敏感等级
├── riskScore: number          # 风险分 0-100
├── owner: string              # 负责人
├── fieldCount: number
├── updatedAt: string
└── fields: Field[]            # 字段列表

Field（字段）
├── id: string
├── name: string               # 字段名
├── description: string
├── dataType: string           # 数据类型
├── category: string           # 数据分类
├── level: string              # 敏感等级
├── regulation: string         # 依据法规
└── riskScore: number

LineageNode（血缘图节点）
├── id: string
├── label: string
├── domain: string
└── level: string

LineageEdge（血缘图边）
├── source: string
├── target: string
└── label: string              # 关系描述（可选）
```
